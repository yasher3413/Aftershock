# Puckquake Goal Bot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Post every NHL regular-season goal to X within seconds, with a rule-written story, the playoff-odds change, and the goal's share card; delete overturned goals and reply with credit corrections.

**Architecture:** A new `aftershock.bot` package inside the existing services: pure text composition (`text.py`), a thin X API client (`x.py`), and an orchestrator (`poster.py`) that the live worker feeds from the same place it already triggers web push and Discord. One queue and one consumer task keep posts in goal order and off the worker's critical path. Post ids live in a new `bot_posts` table; the monthly spend counter and the off switch live in Redis.

**Tech Stack:** Python 3.12, httpx, SQLAlchemy async + Alembic, Redis, pytest (asyncio auto mode), cairosvg for the card (already used by `/api/og`).

**Spec:** `docs/superpowers/specs/2026-10-23-goal-bot-design.md`

## Global Constraints

- Regular season only: `games.game_type == 2`. Preseason and playoff goals are never posted.
- Every post ≤ 280 characters; when over, drop the context clause first, then the assists line.
- No links in any post. No AI-written text.
- Posts go out in goal order; never post a goal whose `created_at` is more than 15 minutes before the post would go out.
- At most one post per tremor id, across restarts and duplicate messages.
- Bot never blocks or slows the worker; every bot error is logged and swallowed.
- Monthly cap default $40; per-call costs: post $0.015, media upload $0.005, delete free. Track in integer tenths of a cent (post 15, upload 5, cap 40000).
- Modes: `off` (default), `dry_run`, `live`. Redis key `aftershock:bot:mode` overrides the `X_BOT_MODE` setting. `live` without all four X keys behaves as `off`.
- Code, package, table and key names use `aftershock`; user-visible text says Puckquake.
- Commits: short imperative subject under 72 chars, no prefixes like `feat:`, no attribution trailers, no em dashes; push after each commit (repo rule, overrides the template's `feat:` style).

## Review Focus

1. A goal reversed or corrected before its post went out (still in the queue, or skipped as stale): no crash, no orphan delete or reply. Test in Task 4.
2. X returns 429 or 5xx: backoff, then give up on that goal after the retry window without blocking the goals behind it for longer than the window. Test in Task 4.
3. Worker restart mid-night replays recent tremors through `_notify` (catch-up is off by then for new goals only): the `bot_posts` row and the 15-minute rule prevent a second post. Test in Task 4.
4. Unassisted goal, goal with no scorer record (`scorer is None`), and a 20-plus-character name: text still valid and within 280. Test in Task 1.
5. Card rendering fails (Cairo missing or a render error): the post goes out text-only rather than not at all, and that is logged. Test in Task 4.

# tremor() has no goalie, which would read as an empty net; give the base one.
def base(**kw):
    return tremor().model_copy(update={"goalie": S.PlayerRef(id=7, name="Juuse Saros"), **kw})

def test_moment_rules():
    t = base()                                   # ties it late
    assert moment(t) == "ties it 2-2"
    late_go_ahead = t.model_copy(update={"score_before": S.Score(home=2, away=2), "score_after": S.Score(home=3, away=2)})
    assert moment(late_go_ahead) == "breaks a 2-2 tie with 20 seconds left"
    early = late_go_ahead.model_copy(update={"t_period_s": 300})
    assert moment(early) == "puts the Canadiens ahead 3-2"
    two_min = late_go_ahead.model_copy(update={"t_period_s": 20 * 60 - 192})
    assert moment(two_min) == "breaks a 2-2 tie with 3:12 left"
    assert moment(t.model_copy(update={"period_type": "OT", "period": 4})) == "wins it in overtime"
    assert moment(t.model_copy(update={"shootout": True, "period_type": "SO"})) == "wins it in the shootout"
    first = t.model_copy(update={"score_before": S.Score(home=0, away=0), "score_after": S.Score(home=1, away=0)})
    assert moment(first) == "opens the scoring"
    lead = t.model_copy(update={"score_before": S.Score(home=3, away=1), "score_after": S.Score(home=4, away=1)})
    assert moment(lead) == "makes it 4-1"
    cut = t.model_copy(update={"score_before": S.Score(home=1, away=3), "score_after": S.Score(home=2, away=3)})
    assert moment(cut) == "cuts it to 3-2"
    en = lead.model_copy(update={"goalie": None})
    assert moment(en) == "makes it 4-1 into the empty net"

def test_compose_matches_agreed_shape():
    t = base().model_copy(update={"assists": [S.PlayerRef(id=2, name="Nick Suzuki"), S.PlayerRef(id=3, name="Lane Hutson")]})
    assert compose(t, "the biggest goal of the night") == (
        "🚨 Cole Caufield & Co ties it 2-2\n"
        "NSH 2, MTL 2 · 3rd period\n"
        "Magnitude 6.4, the biggest goal of the night\n\n"
        "Playoff odds\n"
        "Canadiens: 32.6% → 38.0%\n"
        "Predators: 35.6% → 33.0%\n\n"
        "Assists: Suzuki, Hutson\n"
        "#GoHabsGo #Preds"
    )

def test_compose_shootout_shows_final_score():
    t = base().model_copy(update={"shootout": True, "period_type": "SO", "score_after": S.Score(home=2, away=2)})
    assert "NSH 2, MTL 3 · SO" in compose(t, None)

def test_compose_budget_and_missing_parts():
    long = base().model_copy(update={"scorer": S.PlayerRef(id=9, name="X" * 120),
        "assists": [S.PlayerRef(id=2, name="Y" * 60), S.PlayerRef(id=3, name="Z" * 60)]})
    text = compose(long, "the 2nd-biggest goal of the season")
    assert len(text) <= 280 and "season" not in text and "Assists" not in text
    bare = base().model_copy(update={"scorer": None, "assists": []})
    assert compose(bare, None).startswith("🚨 Canadiens goal ties it 2-2") and "Assists" not in compose(bare, None)

def test_context_clause():
    assert context_clause(6.0, [5.0, 4.0], None) == "the biggest goal of the night"
    assert context_clause(6.0, [5.0], None) is None            # fewer than 3 goals tonight incl. this one
    assert context_clause(6.0, [6.5, 4.0], None) is None
    assert context_clause(6.0, [5.0, 4.0], 2) == "the 2nd-biggest goal of the season"
    assert context_clause(6.0, [5.0, 4.0], 1) == "the biggest goal of the season"
    assert context_clause(6.0, [5.0, 4.0], 4) == "the biggest goal of the night"

def test_correction_and_alt_text():
    assert correction({"scorer": S.PlayerRef(id=5, name="Morgan Rielly")}, {"scorer": "Troy Stecher"}) == \
        "Correction: goal now credited to Morgan Rielly (from Troy Stecher)."
    assert correction({"assist1": S.PlayerRef(id=6, name="Brandon Duhaime"), "assist2": None},
                      {"assist1": "Morgan Rielly", "assist2": "John Tavares"}) == "Correction: assists now Duhaime."
    assert alt_text(base()) == "Magnitude 6.4 goal by Cole Caufield & Co. Canadiens playoff odds +5.4 points, Predators −2.6."

def test_every_team_has_a_voice():
    assert len(TEAM_VOICE) == 32 and all(tag.startswith("#") for _, tag in TEAM_VOICE.values())
